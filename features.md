# Features & Module Specifications

## 🎯 Public Portfolio Landing Page

### 1. Hero Section
- **Dynamic Profile Details**: Displays headline, bio text, and downloadable resume trigger managed from Admin Dashboard.
- **Social Media Quick Links**: GitHub, LinkedIn, Twitter/X, and Email dynamically rendered from database settings.
- **Interactive Quick Metrics**: Years of experience, production projects, and core tech stacks.

### 2. Projects Showcase
- **Curated Flagship Projects**: Features enterprise implementations including MedSync PRO, Real-Time EPOS & KDS, GCC Automotive E-Commerce, Multi-Vendor Marketplaces, and Auction Engines.
- **Rich Project Detail Views**: Dedicated show pages featuring architecture overviews, technical challenges solved, stack tags, and repository/demo links.

### 3. Interactive Skills Matrix
- **Category Grouping**: Grouped into Frontend, Backend, Database/DevOps, and Tools/Libraries.
- **Tech Stack Badges**: Interactive badges with vector tech iconography.

### 4. Professional Experience & Leadership
- **Executive Narrative Layout**: Cohesive, detailed paragraphs highlighting architectural ownership, team leadership, throughput improvements, and mission-critical milestones.

### 5. Technical Blog & Engineering Case Studies
- **High-Level Publications**: Engineering whitepapers on WebSocket dispatching, ESC/POS hardware integration, 100 Google Lighthouse performance engineering, and clinical SOAP inventory math.
- **Dedicated Reading View**: Syntax-highlighted code snippets, architecture callouts, reading times, tags, and previous/next article navigation.

### 6. Contact & Inquiries Module
- **Real-Time Inertia Contact Form**: Submits messages directly into the database inbox with toast feedback.
- **Rate Limit & Bot Prevention**: Rate limiting applied to backend endpoints.

---

## 🔒 Admin Dashboard Panel (`/admin`)

### 1. Dashboard Overview
- **Key Metrics Summary**: Stat cards displaying Total Projects, Total Articles, Total Skills, and Testimonials count.
- **Quick Action Bar**: Shortcuts to publish new articles, add projects, or update settings.

### 2. Projects Manager
- **CRUD Operations**: Create, edit, reorder, and remove portfolio projects.
- **Media & Link Management**: Manage thumbnail images, live demo URLs, and GitHub repository links.

### 3. Articles CMS
- **Technical Writing Editor**: Draft and publish long-form technical case studies with custom slugs, excerpts, and rich formatting.

### 4. Experience & Skills Managers
- **Experience Editor**: Manage company names, job titles, tenures, and narrative paragraphs.
- **Skills Editor**: Add and organize technical skill badges.

### 5. Profile & Site Settings Editor
- **Live Profile Customizer**: Edit headline title, bio paragraph, resume URL, contact email, and social media handles.
